# Week 1, Day 2: Git and GitHub

*2026-10-27 to 2026-10-28*

## Plan

Put the project on GitHub, then learn branches and pull requests by doing one end to end.

## What I did

- **Logged in to the GitHub CLI** with `gh auth login` (device flow). The interactive prompts hung through Claude Code's `!`, but approving the code in the browser worked.
- **Privacy check before going public.** All 11 commits carried my real Gmail address. Before the first push, Claude rewrote them to use the GitHub noreply address and set it as this repo's `user.email`. The file contents were verified identical, and the backup refs were removed. I learned that commit IDs changed because an ID is a hash of everything in the commit, including the author.
- **Created the public repo** `allenren97/mihotel` with `gh repo create`, checked the remote (`git remote -v`), and pushed with `git push --set-upstream origin main`.
- **First pull request, PR #1:**
  - `git switch -c docs/update-readme-status`
  - edited the README in VS Code (`code README.md`)
  - `git diff`, then `git add README.md`, then `git diff` (empty!), then `git diff --staged`
  - `git commit`, then `git push -u origin docs/update-readme-status`
  - opened the PR in the **GitHub web UI**, then merged it in the UI (as a merge commit, the default)
  - `gh pr merge` handled the local cleanup, and `git push origin --delete` removed the remote branch

## Questions I asked

- Why `git switch -c` and not `git checkout -b feature/...`?
- Does a branch start from `main` or from where I am? (From where I am.)
- What's the right workflow? What does `-u` do? How does `git diff` work?
- What's the difference between `git add .` and `git add <file>`? What is `code`?
- Does GitHub have a PR web UI like Bitbucket's? What's the Git command for a PR? (There isn't one: PRs are a hosting-service feature, not part of Git.)
